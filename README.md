# ExercisesForApplication

Dvi algoritminės užduotys, išspręstos C# kalba. Užduočių sąlygos pateiktos faile `Net užduotys.pdf`.

## ClockArrowDegree
Apskaičiuoja kampą tarp laikrodžio valandų ir minučių rodyklių.
- Vartotojas įveda valandas ir minutes, programa tikrina, ar įvestas laikas realus.
- 24 valandų laikas paverčiamas į 12 valandų.
- Grąžinamas mažesnis kampas (≤ 180°).
- Skaičiavimą galima kartoti tiek kartų, kiek reikia.

## TreeDepth
Rekursiškai apskaičiuoja medžio, kurio šakos gali turėti bet kiek vaikų, gylį.
- `Medis` klasė su šakų (`Saka`) sąrašu;
- `Gylis()` grąžina ilgiausią kelią nuo šaknies iki lapo.
